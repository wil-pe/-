# Terminologie — Agent N (nutrition et production de muscle, voie A)

Colonnes : terme (fr) | équivalents par langue | sens précis / piège | source du terme.
« Vu dans » = terme effectivement rencontré dans une source enregistrée ; « requête » = terme utilisé pour chercher mais non relevé dans une source enregistrée (à valider par un locuteur ou une source native).
