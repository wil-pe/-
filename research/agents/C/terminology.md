# Terminologie multilingue — Agent C (viande cultivée de poulet)

Termes natifs relevés dans les sources consultées pendant la session (colonne « attesté dans »). Quand un terme n'a été vu que dans une requête ou un moteur de recherche, c'est indiqué. Les termes réglementaires sont donnés dans la forme exacte du texte officiel.

**Avertissement de fiabilité** : la colonne « Attesté dans » ne garantit que les termes **en** et **fr** et ceux des langues des sources citées (zh : SRC-C-0021/0022 ; ja : SRC-C-0026 et J-STAGE ; ko : SRC-C-0025 ; de : SRC-C-0042). Les autres équivalents (en particulier beaucoup de cases ja/ko et certaines cases zh/es/de) sont des **traductions terminologiques proposées par l'agent C, non vérifiées dans une source de la session** ; les cas les plus incertains portent la mention « non attesté ». À valider avant d'être utilisés comme mots-clés exclusifs.
