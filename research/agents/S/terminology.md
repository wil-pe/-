# Terminologie multilingue — Agent S (substituts : nutrition, énergie, coûts, arôme)

Chaque terme a été rencontré dans une source lue pendant la session (colonne « source du terme ») ou utilisé comme requête dans le journal. Les termes déjà consignés par l'agent A (HME, HMMA, 素鸡, 腐竹, tempeh…) ne sont pas répétés.
