# Questions de recherche

Priorité : **P1** = détermine les conclusions principales / l'innovation ; **P2** = nécessaire à la comparaison ; **P3** = contexte.
Chaque question a un agent responsable et, le cas échéant, des agents contributeurs. L'état de couverture est suivi dans `coordination/coverage_matrix.md`.

## Questions transversales (coordinateur X)

| ID | Question | Prio | Agents |
|---|---|---|---|
| RQ-X1 | Pour chaque voie (A élevage, B culture cellulaire, C substituts), quel est le coût **mesuré** actuel par kg de produit comestible, et quels sont les coûts **projetés** (avec la nature de chaque chiffre) ? | P1 | E, N, C, A |
| RQ-X2 | Quelle quantité de ressources (aliment/substrat, énergie, eau, terres, GES) faut-il par kg de **protéine comestible** dans chaque voie, sur une base de calcul homogène ? | P1 | E, N, C, A |
| RQ-X3 | Quels goulets d'étranglement sont **partagés** entre les voies (ex. approvisionnement en acides aminés : aliment volaille, milieu de culture, protéine texturée) et permettent des systèmes hybrides ? | P1 | tous |
| RQ-X4 | Quel est le statut réglementaire de chaque technologie dans les juridictions clés (UE, France, États-Unis, Singapour, Royaume-Uni, Israël, Chine, Corée, Japon, Australie/NZ, Brésil, Suisse) ? | P2 | E, N |
| RQ-X5 | Où se situent les espaces d'innovation les moins explorés, et quelles expériences permettraient de les tester rapidement et à faible coût ? | P1 | P, tous |
